1. SYSTEM ARCHITECTURE OVERVIEW
========================================================================================================================

The Privacy-Preserving Federated Healthcare Diagnosis Platform consists of two cooperative services running locally:

  1. FastAPI Asynchronous Backend Server (Port 8000):
     - Executes Federated Averaging (FedAvg) aggregation across 4 hospital nodes.
     - Implements Laplace Differential Privacy (epsilon = 1.5, sensitivity clipping C = 1.0).
     - Provides Explainable AI (Linear SHAP feature attribution) for clinical predictions.
     - Manages 5 physically isolated SQLite databases:
         * backend\nodes_db\metro_general.db       (Metro General Hospital - 320 records)
         * backend\nodes_db\st_jude.db             (St. Jude Medical Center - 280 records)
         * backend\nodes_db\city_health.db         (City Health Institute - 250 records)
         * backend\nodes_db\university_research.db (University Research Hospital - 350 records)
         * backend\nodes_db\central_federation.db  (Consortium Hub, Checkpoints & Audit Trail)

  2. React 18 + Vite Frontend Client (Port 3000):
     - Interactive single-page application with modern dark glassmorphism design.
     - Role-scoped workspaces for Doctors, Hospital Administrators, and Research Coordinators.
     - Live SVG/Recharts convergence charts, SHAP risk attribution bars, and streaming training terminals.

6. SOLUTIONS TO COMMON WINDOWS & POWERSHELL ERRORS
========================================================================================================================

----------------------------------------------------------------------------------------
ERROR 1: "npm : File C:\Program Files\nodejs\npm.ps1 cannot be loaded because running
          scripts is disabled on this system (PSSecurityException)"
----------------------------------------------------------------------------------------
Cause:
  Windows PowerShell restricts running PowerShell scripts (.ps1) by default. When you type
  'npm' in PowerShell, it tries to invoke 'npm.ps1' which is blocked by the ExecutionPolicy.

Fix:
  In PowerShell, run 'npm.cmd' instead of 'npm':
      npm.cmd install
      npm.cmd run dev
  Our 'setup_and_migrate.bat' and 'start_project.bat' scripts automatically use 'npm.cmd' to
  guarantee you never encounter this error.

----------------------------------------------------------------------------------------
ERROR 2: "The system cannot find the path specified" (Folder path contains spaces)
----------------------------------------------------------------------------------------
Cause:
  Directory paths containing spaces (e.g., "Master project") break batch files that use
  unquoted strings or nested quotation inside 'cmd /k'.

Fix:
  Our launchers use native '/D' working directory switches and relative virtualenv paths
  ('venv\Scripts\python.exe') inside the folder, completely resolving path-with-space bugs.

----------------------------------------------------------------------------------------
ERROR 3: "Port 8000 (or Port 3000) is already in use"
----------------------------------------------------------------------------------------
Cause:
  An earlier instance of Uvicorn (FastAPI) or Node (Vite) is still running in the background.

Fix:
  To find and terminate the process holding port 8000:
    In PowerShell or CMD:
      netstat -ano | findstr :8000
    Note the PID (the number in the rightmost column, e.g., 14820), then run:
      taskkill /PID 14820 /F

  To find and terminate the process holding port 3000:
      netstat -ano | findstr :3000
      taskkill /PID <PID> /F

----------------------------------------------------------------------------------------
ERROR 4: "Python is not recognized as an internal or external command"
----------------------------------------------------------------------------------------
Cause:
  Python was installed without registering its path in the Windows System PATH environment variable.

Fix:
  1. Re-run the Python 3.10+ installer from python.org.
  2. Select "Modify".
  3. Ensure the checkbox "Add Python to environment variables" is checked, and complete the installation.
  4. Restart your terminal window.
