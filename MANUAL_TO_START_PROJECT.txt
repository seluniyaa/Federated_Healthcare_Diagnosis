Run each component manually in separate terminal windows:

  --------------------------------------------------------------------------------------
  TERMINAL 1: BACKEND SERVER (FastAPI)
  --------------------------------------------------------------------------------------
  cd "C:\Users\gkthi\Desktop\PROJECTS\Master project\Federated_Healthcare_Diagnosis\backend"

  # If virtualenv is not created yet:
  python -m venv venv

  # Install requirements and build databases:
  venv\Scripts\python.exe -m pip install -r requirements.txt
  venv\Scripts\python.exe init_real_databases.py

  # Start the FastAPI server:
  venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

  -> Verify backend is online: Open http://127.0.0.1:8000/docs in your browser.

  --------------------------------------------------------------------------------------
  TERMINAL 2: FRONTEND CLIENT (React + Vite)
  --------------------------------------------------------------------------------------
  cd "C:\Users\gkthi\Desktop\PROJECTS\Master project\Federated_Healthcare_Diagnosis\frontend"

  # Install frontend dependencies:
  npm.cmd install

  # Start the Vite development server:
  npm.cmd run dev

  -> Open http://localhost:3000/ in your browser.
